# Acceptable Use of Company Systems

Company devices and accounts are for business use. Limited personal use is allowed if it does not affect your work or break any rule in this policy.

## Software

Install only software from the Software Center or software approved by IT. Do not install unlicensed or pirated software.

## Company data

Store company files only in approved locations, such as the company drive. Do not upload confidential data to personal cloud storage or to public AI tools.

## Reporting security issues

Report a suspected phishing email with the "Report phishing" button in your mail client. If you clicked a link or entered a password in a suspicious message, tell IT Service Desk immediately.
